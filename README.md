# ЭНЕРГОРЕСУРС — лендинг аренды генераторов

Одностраничный сайт для аренды дизельных генераторов 30–500 кВт (Самара и область),
реализованный из дизайна Claude Design (`ЭНЕРГОРЕСУРС.dc.html`).

## Что в репозитории

- **`tilda/`** — готовые блоки для сборки на **Tilda** (тип блока «T123 / HTML»),
  сверху вниз от шапки до футера. Инструкция по сборке — в `tilda/README.md`.
- **`index.html`** — та же страница, целиком собранная из блоков (для
  предпросмотра и деплоя как обычная статика).
- **`assets/hero-gen2.png`** — исходное изображение генератора (в блоках вшито
  как data-URI).

## Особенности

- Полностью **адаптивная** вёрстка: проверено на 390 / 768 / 1280 px — без
  горизонтальной прокрутки, с мобильным бургер-меню и перестроением сеток.
- Без внешних зависимостей и без сборки: чистый HTML + CSS + ванильный JS.
- Интерактив: квиз-калькулятор (в hero и во всплывающем окне), калькулятор
  стоимости на ползунках, аккордеон FAQ, индикатор рабочего времени,
  прогресс-бар прокрутки, анимации появления, счётчики, бегущая строка,
  плавающие кнопки мессенджеров и CTA.

## Как открыть

Откройте `index.html` в браузере или раздайте статикой (GitHub Pages, Nginx,
`python3 -m http.server`). Для Tilda — см. `tilda/README.md`.

## Замечания по деплою

- Логотип грузится с Tilda CDN, шрифт Montserrat — с Google Fonts. При офлайн-
  открытии они подменяются системным шрифтом и alt-текстом; в проде грузятся.
- Телефон, e-mail, ссылки на мессенджеры и карту в футере замените на свои.
