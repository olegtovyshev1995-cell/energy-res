# ЭНЕРГОРЕСУРС — лендинг аренды генераторов

Одностраничный сайт для аренды дизельных генераторов 30–500 кВт (Самара и область).

Реализовано из дизайна Claude Design (`ЭНЕРГОРЕСУРС.dc.html`) в самостоятельную
статическую страницу — без сборки, без внешних зависимостей и без React.

## Файлы

- `index.html` — готовая страница со всей вёрсткой и логикой в одном файле.
- `assets/hero-gen2.png` — изображение генератора в hero-секции.

## Как открыть

Просто откройте `index.html` в браузере или раздайте папку любым статическим
сервером (GitHub Pages, Nginx, `python3 -m http.server` и т. п.).

## Что внутри

Исходный дизайн был в формате Claude Design (`<x-dc>`, `<sc-if>`, `<sc-for>`,
`{{ … }}`), который рендерится через React-рантайм. Здесь тот же шаблон
встроен в страницу и интерпретируется небольшим ванильным рантаймом
(`<script>` в конце `index.html`): он резолвит условия/циклы/подстановки и
точечно патчит DOM, поэтому сохраняются фокус в полях, каретка и CSS-анимации.

Интерактив:

- Квиз-калькулятор в hero и в модальном окне (4 шага → контакт → заявка).
- Слайдерный калькулятор стоимости аренды (мощность × срок, скидка за срок).
- Аккордеон FAQ.
- Индикатор «Сейчас работаем» по времени МСК (Пн–Пт 8:00–17:00).
- Прогресс-бар прокрутки, появление блоков при скролле, счётчики цифр,
  бегущая строка клиентов, плавающие мессенджеры и CTA.

## Замечания по деплою

- Логотип в шапке грузится с Tilda CDN, шрифт Montserrat — с Google Fonts.
  При офлайн-открытии они подменяются alt-текстом и системным шрифтом; в
  проде подгружаются нормально. При желании их можно так же положить в `assets/`.
